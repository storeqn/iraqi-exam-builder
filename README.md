# أسئلتي — منشئ الأسئلة الامتحانية العراقي

تطبيق عربي لإعداد ورقة امتحانية عراقية، بتصميم **ENG BAHAA**. يعمل من المتصفح ويحفظ الأوراق والقوالب وبنك الأسئلة والملفات الشخصية محليًا باستخدام IndexedDB. للتواصل وطلب تصميم موقع أو تطبيق خاص: [07731378313](https://wa.me/9647731378313).

## التشغيل محليًا

استخدم Node.js 22.12 أو أحدث.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

ينفذ أمر البناء فحص TypeScript ويولد النسخة الثابتة داخل `dist`. لا يتطلب التطبيق حسابًا أو قاعدة بيانات خارجية أو متغيرات بيئة.

## طريقة الاستخدام

1. أنشئ ورقة فارغة أو اختر قالب الابتدائية أو الثانوية أو الرياضيات.
2. عبّئ بيانات المدرسة والمادة والصف والامتحان حسب حاجتك. يمكن إخفاء ترويسة الوزارة أو تفريغ الحقول التي لا تريد عرضها. احفظ بيانات المدرسة والمدرس لاستخدامها في ورقة أخرى.
3. أضف الأسئلة والخيارات والفروع والجداول. غيّر ترتيب الأسئلة بالسحب من المقبض أو باستخدام زري النقل. يعرض المحرر فرق الدرجات عند وجوده.
4. اضغط «معادلة» داخل السؤال لإدراج الصيغ عند موضع الكتابة. يمكن النقر على معادلة موجودة لتعديلها. يوفّر «رسم هندسي» الأشكال والمحاور ورسم دالة بدلالة `x` في المجال `[-10, 10]`، مع إمكانية تنزيل الرسم بصيغة SVG.
5. راجع المعاينة واختر هوامش الورقة واتجاهها وخطها وتباعد الأسطر. استخدم خيارات الطباعة والتصدير في أعلى المحرر.
6. احفظ السؤال في البنك لإعادة استخدامه. من الإعدادات يمكنك تنزيل نسخة احتياطية JSON تشمل الأوراق والقوالب والبنك والملفات الشخصية والإعدادات. يضيف الاستيراد ورقة منفصلة، فيما تدمج استعادة النسخة الاحتياطية البيانات حسب المعرّفات وتستبدل إعدادات التطبيق.

## التصدير والطباعة

| الخيار | الناتج |
| --- | --- |
| PDF | صفحات A4 عالية الدقة مطابقة لتخطيط المعاينة. الصفحات مضمنة كصور، لذلك لا يتوفر تحديد النص أو البحث فيه. |
| Word | ملف DOCX بنص وجداول قابلة للتحرير واتجاه RTL. المعادلات والرسوم والصور مضمنة كصور. لتقريب الخط من المعاينة، ثبّت الخط المختار على جهاز Word. قد تختلف فواصل الصفحات حسب الخط وإصدار Word. |
| PNG وJPEG | صورة عالية الدقة لصفحة واحدة أو ZIP يحتوي صورة لكل صفحة. |
| طباعة | نافذة الطباعة الأصلية للمتصفح. اختر A4 وأوقف ترويسات المتصفح وتذييلاته إذا كانت مفعّلة. يوفر خيار حفظ PDF في نافذة الطباعة مسارًا إضافيًا يدعم تحديد نص الورقة بحسب المتصفح. |
| مشاركة | جهّز الملف أولًا ثم اضغط «مشاركة الملف» واختر التطبيق الذي تريد، مثل واتساب. عند غياب مشاركة الملفات، ينزّل التطبيق الملف ويمكن إرفاقه يدويًا. |

تعتمد الجودة النهائية للطباعة على إعدادات المتصفح والطابعة. المعادلات شديدة العرض قد تحتاج إلى تقسيمها إلى معادلات أقصر. تقسيم النص الطويل يحافظ على محتوى السؤال ويستعمل أسطرًا وصفحات إضافية حسب إعدادات الورقة، وقد تنقسم الجداول الطويلة عند استمرارها عبر الصفحات. اختبر التصدير على جهازك إذا كانت الورقة كبيرة جدًا أو تحوي صورًا كثيرة، خصوصًا في المتصفحات ذات حدود الذاكرة المنخفضة.

## التثبيت والعمل دون اتصال

على iPhone وiPad افتح الموقع في Safari واختر «مشاركة» ثم «إضافة إلى الشاشة الرئيسية». على المتصفحات التي تتيح التثبيت، يظهر زر التثبيت داخل الدليل وفي قائمة المتصفح. يحتاج أول تحميل إلى اتصال وHTTPS في الإنتاج. بعد اكتمال تثبيت Service Worker وتخزين الأصول مؤقتًا، تتوفر الوظائف المحلية دون اتصال. حذف بيانات الموقع أو تبديل النطاق أو المتصفح يعزل الأوراق الموجودة، لذا انقلها باستخدام النسخ الاحتياطي عند الحاجة.

## النشر على Cloudflare Pages

1. افتح **Workers & Pages** ثم أنشئ مشروع **Pages** باستخدام تكامل GitHub. اختر المستودع `storeqn/iraqi-exam-builder`.
2. استخدم الإعدادات التالية ثم شغّل النشر الأول.

| الإعداد | القيمة |
| --- | --- |
| Production branch | `main` |
| Root directory | جذر المستودع |
| Framework preset | React (Vite) |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node.js | الإصدار 22 وفق `.node-version` |

3. افتح رابط `pages.dev` المخصص للمشروع. يستخدم التطبيق مسارات hash، لذلك تبقى التنقلات داخل المستند نفسه. يدعم Service Worker الرجوع إلى مستند التطبيق دون اتصال.
4. إذا أردت نطاقًا مخصصًا، افتح **Custom domains → Set up a domain** داخل مشروع Pages، وأكمل تهيئة DNS الظاهرة في اللوحة وانتظر حالة **Active** وتفعيل HTTPS. راجع [وثائق Git integration](https://developers.cloudflare.com/pages/configuration/git-integration/) و[Custom domains](https://developers.cloudflare.com/pages/configuration/custom-domains/).

## تنظيم المصدر

- `src/model.ts` و`src/storage.ts` لنماذج البيانات والتحقق والحفظ والنسخ الاحتياطي.
- `src/App.tsx` و`src/Dashboard.tsx` و`src/ui.tsx` للتنقل ولوحة التحكم والهوية والتثبيت.
- `src/ExamEditor.tsx` و`src/ExamForm.tsx` و`src/QuestionEditor.tsx` و`src/RichEditor.tsx` لتحرير الأوراق والأسئلة.
- `src/MathEditor.tsx` و`src/GeometryEditor.tsx` و`src/diagram.tsx` للمعادلات والرسوم.
- `src/paper.tsx` و`src/exports.ts` و`src/word.ts` و`src/ExportPanel.tsx` للمعاينة والطباعة والتصدير.
- `src/Bank.tsx` و`src/Settings.tsx` للبنك والإعدادات.
- `public/` و`vite.config.ts` لأيقونات التطبيق وتهيئة PWA والاستضافة.
